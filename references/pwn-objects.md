# 对象、缓存与析构路径

用于"别名/槽号/句柄"驱动的缓存失效、入口缓存指针、释放后复用、标签校验与清理路径。先确定"谁验、谁用、谁释放"，再决定链要不要塞进同一次回调。

## 身份与缓存键

- 缓存/引用失效的判据若是槽号、句柄 id、名字字符串而不是对象身份或版本号，就有绕过空间：让同一对象以两个槽号或两个容器引用（导出再导入、装备表加背包、控制块加数据集），经 A 建立缓存、经 B 改大小或释放，再回 A 读。
- 判据：A 返回旧地址旧长度 → UAF 读写；A 返回新值 → 存在身份/版本校验，换突破点。同样的模式在 Web 侧是写入后读旧值、再换 zone 不匹配路径或等价格式读新值，用来证明"同一逻辑对象、不同字符串 key"。
- "内联数据不被 GC 搬"不是引擎无关结论：先用 addrof 确认对象地址跨两次 GC 不变、内联区可写，再依赖它造伪对象；换长度阈值或换引擎会走外部缓冲，前提消失。

## 入口缓存与一次性链

- 分发/回调入口把对象指针读进栈局部变量、之后才做多次 DMA/MMIO/子调用时，整链要在一次回调内完成（先释放、再分配、再写覆盖），收尾才会用入口缓存的那份指针；收尾会回读全局表则可跨回调分步。
- fork 服务里子进程改的状态不自动回写父进程：需要跨进程回写（同址 iovec）或共享页；父进程检查的一次性标记，先在本地确认它是否被 fork 继承、是否每次连接重建。

## 释放、复用与标签

- 短路径先释放临时块/payload、随后仍用同一指针拼响应 → 响应头会带空闲链表或堆指针，可反复触发取堆/PIE 基址；仅当回包确实复用被释放块、且释放后没被同名分配取回时成立。
- 标签结构（HMAC/SipHash）先找"校验时被屏蔽的字段"：同一合法对象经哈希接口与内存 dump 各取一份逐字节 diff，只有少数状态位不同 → 可用可写对象当 MAC 伪造机；整段不同 → 密钥或随机数参与，改走泄密钥。
- 伪造全局链表或事务表后，关闭句柄/进程退出会遍历它：本地先复现正常退出路径，确认会碰伪造对象就"输出 flag 后挂住"或先恢复链表；输出未 flush 时崩溃发生在结果送达之前。

## 表与配置即代码

- 上传接口对表名/长度/校验和有白名单，但同名可重复上传或分块续传时，先发同长度合法封面、再发不同内容覆盖同名文件，验证"校验对象是否对齐执行对象"（只校验首包或首次落地即可绕过）。
- 搬运/拷贝表（源标识,源偏移,目标标识,目标偏移,长度）可配置时，让一条目把一字节搬到目标报文的功能码或长度偏移，可得到"改任意报文头"的写原语；前提是搬运在总线层且不校验内容。
