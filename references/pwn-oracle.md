# 一比特 oracle 与预算

用于只有存活/超时/退出码/长度/分数一类单比特反馈的题，以及内核 slide、JIT 类型漂移、认证窄化等"把差异变成读取原语"的场合。核心是先定标、再按预算选形态，不要先写循环。

## 先定标，再算预算

- 任何 oracle 先在已知值上测边界语义（差一、tie、大小写归一、NULL），再全量提取；提取结果用独立手段交叉验证（排序 oracle 读到的大小写用 binary 逐位复核——整串比较只约束首个差异位）。
- 预算 = 每请求信息量 × 可并发连接数 × 时限。未知量是整段内存时，1 bit/请求的位测试要 `8n + 验证` 次；先测单请求耗时与可并发度，再决定"位测试 + 精确验证"还是"全候选枚举"。
- 每请求都能独立新连接 → 可并发、按位测试（canary 逐字节、fd 内容逐字节）；只能单连接串行且有一次性标记 → 改造成长度泄漏或多命中，把每请求信息量抬到 1 bit 以上，别硬堆请求。
- 只有一档反馈时，先造"必然通过"和"必然失败"两个样本；没有定标样本就只能记"分档测绘"，不能把某一档当合法字符集或部分正确。

## 反馈形态

- 崩溃/存活、超时、退出码、返回长度、错误码、分数差、连接是否被复用都可以是 1 bit；`cmp al,[rsi-1]` 型 gadget 可造阻塞/崩溃双态，但先确认进程模型、超时与 fork 行为。
- 有回显但只有"对/错"两态时，优先把未知量编码进可读回的数字字段（长度、计数、下标），用"落在哪个预划区间/整除关系"代替崩溃探针。
- 拒绝晚于读入：路径/命令先读进固定缓冲、再按内容黑名单拒绝时，被拒输入仍是纯写通道（前提是过滤器不改写长度、不回滚已写缓冲）；先发两次黑名单串看一次性标记是否被消耗。

## 内核与地址空间

- KASLR slide oracle 必须绑定"只有正确候选才成立"的计算：每个候选附带一个由已泄密钥派生的标签再提交；错误候选也能通过的，说明只验了地址可映射性，换成密钥派生量。
- 无符号表内核：取同版本官方包还原带符号 vmlinux（如 vmlinux-to-elf）+ 解析 BTF 导出结构偏移 + 反汇编三点核对；符号地址与运行时泄露自洽、BTF 偏移与反汇编一致才算版本匹配。
- panic 环境（`oops=panic`、`panic=-1`、`quiet`）看不到崩溃栈：每个写原语执行后立刻读回或查 euid/SID，失败把原值写回再试下一个候选，把"哪些偏移可用"变成可累积清单。
- 用户态任意读：`/proc/<pid>/auxv` 按定长 tag/value 解析可一次拿到 PIE 与加载器基址（需知道 PID 命名空间里的编号与读 `/proc` 的权限）；缺项再退回 maps 文本或运行时泄漏。

## 类型与认证形态

- JIT/类型漂移：同一属性先训练成 double、后喂对象或字符串，补丁删掉类型检查或写屏障时可造伪字符串头——用 DataView 把（长度,标志）拼成双字当 double 写入该字段，读回字符串长度看是否可控且落在喷射区间；否则退回 loop phi、COW、写屏障等其它假设。
- 认证窄化：`strncmp/strcmp` 比较摘要或先做字节变换再比较时，找出预期值中 NUL 的位置，构造只需前缀匹配的输入；C 字符串语义（遇 NUL 提前结束）是绕过前提。
