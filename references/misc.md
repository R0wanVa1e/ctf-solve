# Misc 速查

1. **先判协议/容器**：收 banner；列归档成员、媒体 tracks/attachments、pcap 流、镜像分区和隐藏文件。
2. **保留原样**：解包到工作目录；媒体优先 copy 不重编码；记录文件大小、时间戳和哈希。不要直接执行未知样本。
3. **枚举载体**：视频/音频按三种取法分别清点——`-map` 选流、字幕轨正文、附件（`-show_attachments` 看 FileName，`-dump_attachment:t` 按名字落盘；附件不一定能被 `-map` 选中）；pcap 的 keylog、对象、重组流；桌面题的画面、键鼠、剪贴板、DBus。
4. **验证表示链**：过滤器/分类器/沙箱与实际执行可能看到不同表示；检查解码、编译、加载、宏和异常路径的副作用。
5. **模型题**：先探输入/输出与评分函数；白盒时本地批量评估，黑盒时测查询预算与噪声，避免把整体分数误作逐位 oracle。模型权重重复率异常时，检查四种解释：小随机池采样、索引置换、量化、以及"整段 PRNG 流按层切片/重排"（某一行逐位等于序列前 k 项的指纹）；用逐位相等加校验器排除巧合。

工具/协议与取证案例见 [`field-notes/misc.md`](field-notes/misc.md)。重组 TCP/HTTP、裸协议解析查 [协议边界](protocols.md)；统计载密先用多个独立约束复核群体，网络不可达或主题补字的结果保持候选状态，见 [证据规则](evidence.md)。

Agent trace/标签传播题按执行簿追数据与控制依赖；FT8 多帧按 CRC、时序与重发语义核对，两者见 [`field-notes/misc.md`](field-notes/misc.md) 的“卡住”。
