# 卡住时的通用破局清单

任一方向连续 30 分钟没有新的、可验证进展时，先完成一次方法复盘，再按下面清单排查。复盘不是重复列命令，而是用已有证据决定下一次测试。

## 30 分钟复盘记录

在当前题目工作目录的笔记中按 [阻塞诊断](../blockers.md) 的 `PROGRESS.md` 模板记录：本次的成功条件、最近确认点（原语/输入/输出/版本）、尝试账本、阻塞类别、方法改进与 1–3 个下一步测试。不再维护第二套表。

执行规则：

- 先用对照组确认观测不是网络抖动、超时或环境差异；远程题保持低频、只触达题目靶场。
- 每轮只改变一个关键假设，从最近确认点继续；测试完成后更新账本。再连续 30 分钟无进展时重做复盘。
- 题目结束后提炼有效方法、无效尝试及原因、可复用改进和未解决问题。只有经过证据支持并在其他样本/版本验证的通用改进才回填本技能；单题结论留在题目笔记。

## 十一条破局模式

1. **校验与使用分离**：找到"谁验、谁用"两个组件——验签的是清单、装载的是 entry；校验的是字符串、连接的是解析结果；清缓存看的字段、实际用的对象。两者信息差就是入口。批量执行器"绑定/校验两个数组、执行用原始下标"也属此类。
2. **解码层绕过**：黑名单总在解码前匹配。让 payload 在解码后才成形：编码转换、hex2bin、双重编码、码表替换、大小写（`fl%61g`）；但也要想到**字面量语义层**（PG E-string 里 `\` 才是转义符）和**归一化层**（`./` vs `.//` 归一到同一目录、键却不同）。
3. **Oracle 化**：任何可观测差异都能变逐字节读取原语——延迟（时间盲）、exitCode、连接存活、崩溃与否、返回的字节差、cmp+条件跳转的双态、分数/条数。卡在"拿不到数据"时先造 oracle；注意 oracle 也可能是"读到超时不崩"。**一条 oracle 被封就换维度**：直接比较被 NULL 毒化 → 排序名次（UNION 探针行+派生表 ORDER BY N，赢家标记列可读）；时延被防注入惩罚污染 → 纯布尔/缓存命中标记；CI 排序丢大小写 → binary 逐位。每换一个维度都要先在已知值上重新定标。
4. **已知明文 = 判据**：文件头（PNG/ZIP/MZ）、CRC、格式（flag{、UUID、日期）既当爆破成功判据，也当拼接方向验证器。数值/密文派生结果也能当判据（未知字节→KDF→预测 offset/len）。
5. **指纹 → 检索**：CMS/组件版本、题目名、独特报错串、代码片段——WebSearch 现成 POC/writeup。国际题复用率高；国产题先查原厂/国际原型。
6. **diff 思维**：两版本二进制/双固件/运行时内存 vs 静态文件/补丁前后——差异处就是补丁点或自解密逻辑。内核题先按修复 commit 首现版本判缺口；JS/V8 题先 diff 上游补丁。
7. **时序窗口**：释放-复用要落在同一窗口？先在本地副本用受控并发或延时复现并观察状态变化；不要用资源耗尽式请求压慢共享远程服务。泄露与利用必须同进程/同连接时，先确认有没有 `exit` 重启。
8. **多载体清点**：容器里有几条轨/几个附件？桌面题除了屏幕还有键鼠/剪贴板/DBus？流量题除了 pcap 还有 `*.keys`/内存/磁盘镜像？先列全载体再动手，单载体常只给半张图。
9. **协议误判**：连上先收 banner/看首包。RFB≠HTTP，裸 TCP 行 JSON≠HTTP，`bad submission` 可能只是应用层报错；协议没确认前写的 exp 大概率白写。
10. **把数据写进状态机**：不满足于"读"，让伪造数据带业务语义（status/kind/stale、组件 manifest、收据状态、工程表）触发系统的 hook/重载/结算，让系统自己执行副作用——读原语由此升级为写/执行。
11. **表示差异审计**：沿输入到副作用画出 wire bytes → 解码/规范化 → parser/validator → 编译/反序列化 → runtime/下游服务。逐段确认每层实际看到什么；特别检查校验器是否覆盖最终执行对象、编译期是否有副作用、服务端是否仍接受客户端已废弃的字段，以及泄露凭据最终受什么 ACL 限制。最小化地改变同一语义在不同表示中的编码，并用无害输入证明解析差异后再尝试利用。

## 跨方向组合（题面类别 ≠ 所需技术）

| 表面 | 真正需要的第二技术 |
|---|---|
| Web | Crypto（JWT/自定义签名伪造）；Reverse（WASM/混淆 JS）；内网/CI（供应链与横向） |
| Forensics/Misc | Crypto（pcap 里加密数据）；Pwn（pcap 里藏 exploit 重放）；Web（还原攻击后复现） |
| Reverse | Pwn（逆完接着打）；Crypto（自定义密码体制还原）；固件/OTA（派生链+设备） |
| Misc | Crypto（编码链底端是数学）；Web（取证还原攻击后复现）；AI/优化（模型题） |
| PWN | Web（协议/管理面）；Crypto（VM 指令编码/校验和）；内核/虚拟化（独立子领域） |
