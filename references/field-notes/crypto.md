# Crypto 打法

下列参数化条目包含历史单题案例；轮数、权重、BKZ block size、故障位置和概率只适用于原记录的结构。先按生成器推导，再用原方程回代；不要把常量当默认值。噪声/小秘密分流见 [结构模型](../crypto-noise.md)。

## 1. 先识别结构（拿到参数先看这几样）

- 先区分“标准密码原语”与题目自定义 wrapper：阅读自定义运算/数据类型的实现，检查其代数结构、可逆性、闭包、边界条件、序列化和派生键格式；再判断攻击目标是破原语，还是利用可逆操作、输入可塑性、输出 oracle 或旁路元数据。遇到带分数/布尔输出时先建立本地对照并估算每次查询的信息量与状态消耗。
- RSA：n 的分解可能性（yafu / Fermat 相近素数 / 结构化 N 如 p·q·r·(p+q+r)）；e 是否异常（小 e、e=2^k 结构、e|phi）；多组 n 的关系（gcd 共因子）；d 有无部分泄露；**n 的位长拆分是否暗示"中间夹大因子"**
- 对称：模式滥用（CBC/CTR/ECB）、密钥重用、IV 可控、部分密钥缺失、**自定义 ARX/截断**
- 其他：格结构（线性关系+小未知量）、RLWE 判定、PRNG（种子可猜/状态可恢复）、Σ/GQ 类协议
- 泄露物：浮点数组/树/内存块先反推长度与布局（能否整拆成几段、是否 8 字节对齐、被砍掉的头部等于哪段差集），再当"带噪观测"拟合，不要先猜语义

## 2. RSA 套路速查

| 条件 | 打法 |
|---|---|
| e 小 + 短消息 | 直接开方 / Coppersmith |
| 不同模数共享素因子 | gcd(n1,n2)，排除 gcd 为 1 或整个模数 |
| 同 n、同明文、互素指数 | 扩展欧几里得组合密文；负指数需模逆，详见 [结构模型](../crypto-noise.md) |
| 有证据表明 d 小 | Wiener / Boneh-Durfee；e 大本身不保证 d 小 |
| 已知 p 高/低位 | 建立小根多项式并确认次数、因子下界与根界；单变量一次多项式的常见界与 N^(β²) 有关，不能脱离模型套位数余量 |
| 已知 p⊕q | 高位逐位剪枝（n 比对剪枝，先粗后细） |
| 部分泄露 d 低位 | 从 e·d−1=k·φ(N) 推导具体同余，区分泄露位数与乘数 k；不能用同一符号混写两个未知量 |
| 故障签名 | 先确认故障位置；RSA-CRT 单支故障可对正确/故障签名差与 N 求 gcd，逐位故障需另建状态模型 |
| e 含高次 2 因子 | 先分析单位群阶、明文子群与可观测幂残数；仅有 e 的形状不能保证逐位恢复 |
| N 位长 = 小段+大段+小段 | **部分因子**：`β=bitlen(q)/bitlen(N)`、`X<N^{β²}`，先算未知位余量再定 m,t（单例曾用 β≈0.56、m=t=6、12 维；不是默认值）。未知量远小于上界时不必加维；`q=gcd(N, H·2^s+x0)` 后必须验 `q|N`，单因子模解密还要 `gcd(e,q−1)=1`、`m<q`，并用 `pow(m,e,N)==ct` 回验 |
| 截断/半字节固定 | 等价类用脚本枚举去重计数（数值等价与文本等价是两层：大小写、最高半字节自由），别套文档里的乘积 |

## 3. 格攻击（见到"线性关系 + 小未知数"就往格上想）

- LWE/RLWE 判定 → 先分析噪声与秘密尺度，再配平 Kannan embedding；模系数需要时取中心代表元。嵌入坐标权重默认取 1 让目标成为最短向量，只有秘密块与误差块尺度差大、需要配平 w 时才调，并重算 gap——不是越大越好
- **RLWE 逐样本判定（0/1 位）**：信息只在 (s,e) 同时小，"能否线性表示"本身无信息。先算 `det^{1/d}`、高斯启发、目标长度与 gap，由 `δ_β^d ≲ gap` 反解 β；LLL 的 δ≈1.02 在该维度常差几个数量级，直接 BKZ。判 0 要给出构造性 (s,e) 并回代全部样本；判 1 只是否定证据，必须抬 β 复核，记录 β/AUTO_ABORT 与停止条件。模系数先取居中代表元——不居中时 `‖e‖ ~ p√n`，短向量根本不存在；再用 `max|s|,max|e| ≤ ~12σ` 作约束
- **环光滑化不是捷径**：环多项式高度可约时先测 `e mod g` 的系数分布；分量里的误差可能被商搅匀（≈p/2），"小"只在系数基下成立，CRT 拆环是硬化。Kannan 行的指纹是末坐标 ±K、秘密块 ±s，两个方向都要试
- 背包 → 标准 0-1 格（2I+全1行+[pubkey|enc]列）
- AGCD：n_i=p·q_i+m_i 两两**交叉相减**去 p，带权重 2^256 造格
- HNP：消去未知数后造 (2n+1) 维格，配两个比例因子
- 方程组嵌明文：转置取整造 (n+1)×(n+1) 矩阵，关键列加 2^60 权重
- NTRU：`[I H;0 qI]` 2N 维，短行 √(2N)σ≪q，LLL 取 (f,g)，用 h·f≡g 复核
- 多个"和 mod p"未知 → 爆破倍数 i（sum=c+i·p）逐次规约
- 永远留一条独立验证路径：LLL 解出后回代/换算法交叉，不只看"看起来短"

## 4. 谱域/浮点泄露（先反推布局，再拟合，再取整）

- **布局反推**：给一长串 double 先看长度能否整拆（如 `2N + 2N·log₂N + 2N` 对应叶子/内部/叶子），并核 8 字节对齐；头部被砍掉的个数等于差集，先写切片公式再拟合。语义未知时先验比值关系（`G00(ζ)=|f(ζ)|²+|g(ζ)|²`、`G00·G11−G01²=q²`），再决定它是谱、比值还是协方差
- **相位与恒等式**：负循环环上奇次幂采样必须乘半格相位 `exp(−iπk/N)`，否则逆 NTT 整体错半格而取整误差仍"看起来小"。负循环自相关是反对称：`D[k]=−D[N−k]`、`D[N/2]=0`、`D[0]=‖f‖²+‖g‖²`；与正循环的对称性相反，方向写反会把正解判错
- **拟合**：把 n/2 维 log 谱当未知量（保正，避免比值在分母为零处爆），`soft_l1` 的 f_scale 从 1e-2 分级收到 1e-10（先 L1 进盆地再 L2 精修）；内部节点取 O(1) 宽松上界、叶子用中位数定绝对尺度；掩码要同时作用于观测、尺度和雅可比行，否则行数不匹配
- **重尾噪声分层**：double 的 bit0–55 近似无损，bit48–55 落在指数区会跳量级，bit63 直接反号——位翻转、量级跳变、符号翻转三类粗差不能都当高斯；用"物理上界掩码 + 鲁棒损失分级 + 非有限过滤"三者同时，不能只靠 |L| 阈值
- **收尾**：`max|raw−rint|<0.05` + 上述恒等式 + 第二条独立路径（NTRU 格 LLL 取 (f,g)）三者齐备才算解；位长/字节口径先回定义（head 是 double 个数还是字节）
- 密文派生：D 按 `str(int)` 逗号无空格 → `sha256(b"前缀:"+canon)` → 计数器 4 字节大端拼密钥流；任一位错就解出乱码——但"看到 flag{ "只是强候选，最终以重加密/校验器为准

## 5. 自定义 ARX/分组与故障

- 自定义 ARX：先找独立 lane、可逆性和有效密钥截断。对 w-bit 的 `y=x^(x>>n)`（n>0），可用 `x=y^(y>>n)^(y>>(2*n))^...` 直到移位≥w 求逆，再按 w 位截断；用多组正向结果验证。题面声明的密钥位数与代码掩码/取模不一致时以代码为准：枚举 v 与 v+2^有效位，看轮密钥是否相同
- 求原像：正反各 2^k 枚举，指纹 b bit，假匹配期望 `2^{2k−b}`，把 b 取到期望≈1（3 lane/48 bit 是单例参数）；命中后必须用全部 lane 复算，别做 2^k×2^k 全匹配。正向表内存 `2^k × 8B`，先估 RAM 与排序成本
- **轮边界差异**：0 命中先查末轮是否省略末尾异或、轮密钥串联起点、常量端序，这些比扩大枚举更常见。截断造成的多解必须分层报告：两段 7 位 hex 都先 `&0xffffff` 时密文只定每段低 6 位，再叠大小写构成文本等价类；附件加密器全量匹配属 E2，校验器接受才是最终文本
- 持久 S 盒故障（统计指纹优先于猜下标）：统计每字节取值找缺失/重复像集，结合尾掩码重复结构逐字节反推轮密钥，再用 ShiftRows 循环约束逐轮回推；像集缺口与重复数要能解释全部样本
- CBC：可从尾块逆推 `C_{i-1}=Dec(K,C_i)⊕M_i`；IV 被当密文用时 `IV=Dec(K,C_0)⊕M_0`
- CTR 在同 key、同 nonce 与重叠 counter 段复用密钥流，密文异或泄露明文异或；已知明文只直接恢复对应重叠段，不保证全解
- ECB 相等密文块泄露相等明文块，不直接泄密钥；逐字节恢复还需可控前缀与稳定的未知后缀加密 oracle
- **判据用认证标签**：XOF（SHAKE 类）用错长度仍解出同一段前缀明文，块内 CRC 自洽也不证明通过；以 HMAC/认证标签或重加密为准。数值宽度按 `ceil(bit_length/8)`（134 位模数要 17 字节，写死 16 会截断高位）
- 密钥缺几位：printable 枚举 + 已知格式块校验；或尾块解密比对当 oracle 爆破

## 6. PRNG

- MT19937：同一生成器连续、完整、正确对齐的 624 个 32-bit tempered word 可恢复状态并预测；截断输出、randrange 拒绝采样、浮点输出和多 worker 混流另建模型，见 [阻塞诊断](../blockers.md)
- LCG：模数已知且差分可逆时，3 个连续输出解 a、c；模数未知用差分 gcd 求其倍数并验证歧义，见 [结构模型](../crypto-noise.md)
- 时间/日期种子：缩小范围逐个试，用已知明文（flag{）校验
- 输出复用：预测值当方程系数（如范德蒙德）解出隐藏参数
- 权重是打乱的 PRNG 序列：唯一值远少于总量即"小池采样"，指纹行锁起点 + `setdiff1d` 验覆盖 + 日期枚举反推种子
- 权重池种子与置换种子可能相邻而非相同：先用一行逐位相等加全值集合覆盖锁定生成种子，再围绕时间窗口单独枚举置换种子；每个候选直接交给题目校验器，别从“同一随机流”措辞猜调用顺序

## 7. 协议伪造（Σ/GQ 类）

- **承诺来源检查清单**：com 是否必须来自某个 r 的幂、公钥/参数是否在 com 之前打印、e 是否只有少数取值、挑战是否可预测。服务端只验代数关系时，`com=y^{−c}, res=1` 使验证式 `res^e ≡ com·y^chal` 恒等（e=2 时单轮通过率 1/2）
- **可枚举化生成器**：挑战由少量固定常量决定时，从"恢复内部状态"降级为"解 k 个代数方程"（固定平移点集 → 候选 mod x → 单次命中 1/k）；会话每连接重生成参数，必须一轮内闭环，失败重连
- **由记录反求未公开模数**：按验证式构造差式（必须带 `y^chal` 因子），剔除差值为 0 的记录（chal=0 时恒等），再对剩余值求 gcd；位数只作必要条件
