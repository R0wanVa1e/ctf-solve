# 噪声、稀疏性与小秘密

适用于 `b=A·s+e mod q`、带掩码的转录、RSA 分片泄露。先看实际数据的维数、模数和生成约束；注释、默认生成参数与 data 块可能不一致。

## 模型选择

| 可证实结构 | 先试方法 | 接受条件 |
|---|---|---|
| 少数行有噪声，至少 n 行精确 | 枚举/抽样 n 行可逆子系统，模 q 消元 | 全部 m 行残差满足生成器的噪声数量与范围 |
| s 只有 k 个非零位置且 k 小 | 枚举 support，再选 k 个干净独立行 | 检查完整残差、值域；若分片拼 RSA 因子，验证 `N % p == 0` |
| 每轮 `b=A·s+G·y+e`，y 独立 | 把每轮 y 加作局部未知量，s 跨轮共享 | 秩足够，留出行吻合，s 的小系数范围成立 |
| 每样本给 0/1 判定（decisional LWE/RLWE） | 先算 `det^{1/d}`、高斯启发与目标长度差 gap，由 `δ_β^d ≲ gap` 反解 β，再逐样本 BKZ | 判 0 有构造性 (s,e) 并全样本回代；判 1 只是否定证据，须抬 β 复核并记录停止条件 |
| s 极小但 e 较大且密集 | 加权 Kannan 嵌入，再估目标长度与格尺度 | 候选回代全部方程，中心化误差不超界 |
| 无上述结构 | 再考虑一般 LWE/RLWE 格算法 | 参数、代价、失败概率有依据；不能靠题名套模板 |

枚举干净 n 行的单次概率为 `C(m-t,n)/C(m,n)`（t 为噪声行数）；先算组合数与预算。模数未证为素数时，不用 `pow(x,q-2,q)` 冒充通用逆；检查 `gcd(pivot,q)==1`，必要时 CRT 或解同余方程。NumPy 整数乘加可能在取模前溢出，按 q 与维数估界；大模数改 Python 整数或可靠有限域库。

## 掩码与稀疏噪声

左核消去 G 会把多行误差混在一起：原始 e 只有一行非零，也可能污染许多核方程。先在无噪声合成数据上对拍构造，再比较两种模型的原始残差。把 y 并入未知量有时更便宜，也更保留行噪声稀疏性。

RREF 遇矛盾行不能随意丢掉就宣称恢复：噪声若进入 pivot 已污染候选。乱序重选独立方程、迭代剔除或鲁棒估计只负责生成候选，最终必须回代原始方程、核对容许异常数和 s 范围；不足秩时保留自由变量。

## 加权嵌入与符号

采用行基、列顺序 `(误差m维, 秘密n维, 嵌入1维)`：

```text
B = [ q I_m    0       0 ]
    [ A^T      w I_n   0 ]
    [ b^T      0       c ]
v = (e, -w s, c)  （加 q 行的整数线性组合）
```

让秘密块 `w·s` 与误差块的典型尺度接近，并考虑维数对总范数的贡献；w 按尺度配平，嵌入坐标 c 默认取 1（让目标成为最短向量），只有秘密块与误差块尺度差大时才调并重算 gap。模系数先取居中代表元，不居中时 `‖e‖ ~ p√n`，短向量根本不存在。LLL 返回行若最后坐标 `last=±c`，统一符号 `sigma=last/c`，取 `s_j = -v[m+j]/(w·sigma)`，要求整除和秘密范围；不能写“无论整行符号如何都直接取负”。最后坐标为其他倍数时不能按这条公式硬提取。

有 `python-flint` 时可用 `fmpz_mat(...).lll()` 替代只为 LLL 安装整套 Sage；先确认行/列约定。LLL 没找到目标不证明无解。不要仅因 ASCII 可读或 padding 通过打印“已验证”；显式断言全部残差、重加密结果或认证标签。

## 截断且带噪的 LCG / HNP

当生成器给出 `s_i=(A_i*x+B_i) mod m`，种子低 b 位已知时，令 `x=2^b*H+low`。若观测 `y_i=(s_i>>k)+d_i`，`|d_i|≤D`，可写：

```text
P_i = A_i*2^b mod m
T_i = y_i*2^k + 2^(k-1) - A_i*low - B_i mod m
P_i*H - T_i ≡ r_i (mod m)
|r_i| ≤ D*2^k + 2^(k-1)   （低位与噪声合并为一个有界误差）
```

先确认 i=0 是种子还是递推后首状态，再构建 H 一维、n 个模坐标、一个目标嵌入坐标的 n+2 维格。不要机械地为每个低位余数和噪声另开坐标；合并误差常能显著降维。H 的权重按其位长和误差范数配平，嵌入符号按实际行约定提取；目标短向量/行列式余量只是选模依据，不保证 LLL 必成功。

不能把整个同余式直接除以 `2^k` 后丢掉未知低位：后者未必整除。候选逐项验证种子范围、已知低位、全部状态的观测误差及下游密钥派生；CBC 解密必须真做 PKCS#7 检查，`rstrip(b'\x00')` 或看到前缀不算填充验证。来源 `tyr/solve.py` 使用执行数据文本加载参数，复用前改为白名单赋值/字面量解析，不把 `exec(output.txt)` 作为标准解法。

## RSA 与离散对数的低成本分流

- “共因子”：不同模数计算 gcd；“共模”：同一 n、同一明文、多组互素指数，扩展欧几里得组合密文（负指数需模逆）；不能把二者混称。广播攻击须同一明文、互素模数且 CRT 后精确开 e 次方，失败要查前提而非立刻转小 d。
- 素因子线性组合先做有理/整数消元并回代。位长提示只能在生成器确认分片数和首片范围后用于枚举，256-bit N 不独立证明两因子恰各 128 位。
- 对奇数 `a^e mod 2^k`（k≥3），单位群为 `C2 × C(2^(k-2))`；分离符号后对基 5 逐位提升，再解 `t·e≡u mod 2^(k-2)`。t 不可逆时用 gcd 解同余并保留全部候选，结合 e 的范围和原始幂验证。
- LCG 三输出在模数已知且差分可逆时可解 a/c；模数未知可由差分行列式 gcd 得到模数的倍数。没有通用“至少六个就保证恢复”；检查非零信息量、模逆、倍数歧义，并用未参与拟合的后续输出预测。
